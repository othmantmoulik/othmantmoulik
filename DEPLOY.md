## Step-by-Step Instructions

### **Step 1: Create a Render Account** (2 minutes)

2. Click **"Get Started for Free"**
3. Sign up with your **GitHub account** (click "Sign up with GitHub")
4. Authorize Render to access your GitHub

---

### **Step 2: Deploy Your Platform** (3 minutes)

1. Once logged into Render, click **"New +"** button (top right)
2. Select **"Web Service"**
3. Click **"Connect GitHub"** (if not already connected)
4. Find and select your repository: **othmantmoulik/othmantmoulik**
5. Select the branch: **claude/masterclass-clone-platform-ofdlu**
6. Render will auto-detect the settings from `render.yaml`
7. Click **"Create Web Service"**

That's it! Render will now:
- Install all dependencies
- Set up the database
- Start your server
- Give you a live URL

---

### **Step 3: Get Your Live URL** (instant)

1. Wait 2-3 minutes for deployment to complete
2. You'll see a URL at the top: `https://almasterclass-platform.onrender.com`

## 💳 To Enable Payments (Optional - Do Later)

Once your site is live, you can add Stripe:

1. In Render dashboard, go to your service
2. Click **"Environment"** tab
3. Add these variables:
   - `STRIPE_SECRET_KEY` = your Stripe secret key
   - `STRIPE_PUBLISHABLE_KEY` = your Stripe publishable key
   - `STRIPE_MONTHLY_PRICE_ID` = your monthly price ID
   - `STRIPE_YEARLY_PRICE_ID` = your yearly price ID
4. Save changes
5. Service will auto-redeploy with payments working!

Get Stripe keys from: https://dashboard.stripe.com/register

## 🆘 Troubleshooting

**"My service won't start"**
- Check the logs in Render dashboard
- Make sure the branch is correct
- Contact me for help!

**"I want a custom domain"**
- In Render, go to Settings → Custom Domain
- Add your domain (like almasterclass.com)
- Follow DNS instructions
- Free SSL included!

**"How do I see logs?"**
- In Render dashboard, click "Logs" tab
- See real-time server activity

**"I want to change the URL"**
- In Render, go to Settings
- Change the name under "Name"
- New URL will be: `https://new-name.onrender.com`
